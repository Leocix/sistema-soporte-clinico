# Escala de Usabilidad del Sistema (SUS)
**Instrumento de Evaluación (OE5)**

**Objetivo:** Medir el nivel de usabilidad de la plataforma web y la aplicación móvil construidas[cite: 1].
**Instrucciones:** Califique cada afirmación en una escala del 1 (Totalmente en desacuerdo) al 5 (Totalmente de acuerdo)[cite: 1].

1. Creo que me gustaría utilizar este sistema con frecuencia[cite: 1].
2. Encontré el sistema innecesariamente complejo[cite: 1].
3. Pensé que el sistema era fácil de usar[cite: 1].
4. Creo que necesitaría el apoyo de un técnico para poder utilizar el sistema[cite: 1].
5. Las funciones del sistema están bien integradas[cite: 1].
6. Pensé que había demasiada inconsistencia en el sistema[cite: 1].
7. Imagino que la mayoría de las personas aprenderían a usar el sistema rápidamente[cite: 1].
8. Encontré el sistema muy engorroso de usar[cite: 1].
9. Me sentí muy seguro utilizando el sistema[cite: 1].
10. Necesité aprender muchas cosas antes de poder usar el sistema[cite: 1].

**Cálculo de puntaje:** La meta de aceptación como herramienta de soporte a la decisión clínica es obtener un puntaje final igual o mayor a 80 (SUS ≥ 80)[cite: 1].
